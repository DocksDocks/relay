# Documentation

## Plans

Read `docs/PLAN.md` before you file, read, or update a plan issue. It points to
the v4 plan contract inside the installed `plan-lifecycle` plugin. No plan
markdown is tracked in this repository; the record is a GitHub issue in
`DocksDocks/relay`.

## Reference

`docs/crate-map.md` maps the Rust crate: module responsibilities, the
integration targets, and the invariants each module protects. It is
derived documentation, read on demand. Update it in the same change that moves a
constant or a module boundary it names.
