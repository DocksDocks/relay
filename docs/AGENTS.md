# Documentation

## Plans

Read `docs/PLAN.md` before you file, read, or update a plan issue. It is the
complete plan record standard: the v3 body contract, the label set, the derived
state table, the lifecycle commands, the review-record grammar, and the landing
rules. No plan markdown is tracked in this repository; the record is a GitHub
issue in `DocksDocks/session-relay`.

## Reference

`docs/crate-map.md` maps the Rust crate: module responsibilities, the custody
and deadline constant taxonomy, and the invariants each bound protects. It is
derived documentation, read on demand. Update it in the same change that moves a
constant or a module boundary it names.
